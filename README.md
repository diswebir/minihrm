# مینی‌اچ‌آر‌ام — سامانه مدیریت منابع انسانی 🧑‍💼

سامانه‌ی حرفه‌ای، ماژولار و کاربرپسند مدیریت منابع انسانی با **Node.js** — قابل نصب روی هاست **cPanel بدون نیاز به SSH**، همراه با **ویزارد نصب**، **سطح‌بندی دسترسی کامل**، **فرم استخدام چندمرحله‌ای با QR و OTP**، **مجموعه آزمون‌های روان‌شناختی (MBTI، DISC، هوش هیجانی، علایق شغلی هالند) با تحلیل حرفه‌ای** و **سیستم اطلاع‌رسانی پیامکی هوشمند**.

## 🖥 نصب روی هاست cPanel (بدون SSH)

### پیش‌نیاز
- هاست cPanel با قابلیت **Setup Node.js App** (در اکثر هاست‌های امروزی فعال است)
- Node.js نسخه **۱۸ یا بالاتر** (توصیه: ۲۰ یا ۲۲)

### گام ۱ — آپلود فایل‌ها
1. وارد **File Manager** cPanel شوید.
2. فایل‌های پروژه را در مسیر دلخواه (ترجیحاً **خارج از `public_html`**) مثلاً `~/apps/minihrm` آپلود و اکسترکت کنید.

### گام ۲ — ساخت اپلیکیشن Node
1. در cPanel به بخش **Setup Node.js App** (یا Application Manager) بروید.
2. روی **Create Application** کلیک کنید:
   - **Node.js version**: 18 یا بالاتر
   - **Application mode**: Production
   - **Application root**: مسیر پوشه پروژه (مثلاً `apps/minihrm`)
   - **Application startup file**: `server.js`
   - **Application URL**: دامنه یا ساب‌دامنه دلخواه
3. روی **Create** / **Done** کلیک کنید.
4. در همان صفحه، **Run NPM Install** را بزنید تا وابستگی‌ها نصب شوند.

> 💡 همه وابستگی‌های این پروژه **کاملاً خالص JavaScript/WASM** هستند و به هیچ کامپایلر یا دسترسی SSH نیاز ندارند. (پایگاه داده از SQLite داخلی Node یا نسخه WebAssembly استفاده می‌کند — به‌صورت خودکار تشخیص داده می‌شود.)

### گام ۳ — ویزارد نصب
1. آدرس اپلیکیشن را در مرورگر باز کنید — به‌صورت خودکار به صفحه **ویزارد نصب** هدایت می‌شوید.
2. **گام ۱ — بررسی سیستم و اطلاعات شرکت**: نام شرکت، عنوان سامانه و پیشوند کد پیگیری
3. **گام ۲ — مدیر کل سامانه**: نام کاربری و رمز عبور سوپرادمین (به تمام بخش‌ها دسترسی کامل دارد)
4. **گام ۳ — پیامک**: اتصال IPPanel یا حالت آزمایشی (قابل تغییر بعدی)
5. **گام ۴ — نهایی‌سازی**: نصب انجام و وارد داشبورد می‌شوید.

> ⚠️ پس از نصب، مسیر `/install` قفل می‌شود. برای نصب مجدد، فایل‌های `data/config.json` و `data/app.db` را حذف کنید.

### گام ۴ — پوشه data
پوشه `data/` (پایگاه داده، فایل‌های آپلود و تنظیمات) به‌صورت خودکار ساخته می‌شود. اگر روی هاست خطای دسترسی دیدید، از File Manager مجوز نوشتن آن را بدهید (۷۵۵ یا ۷۷۵).

## 📲 تنظیم پیامک IPPanel (OTP)

1. در پنل [IPPanel](https://ippanel.com) یک **الگوی پیامک (Pattern)** برای کد تایید بسازید که حداقل یک متغیر (جای‌نگهدار) داشته باشد — مثلاً:
   ```
   کد تایید شما: {otp}
   ```
   نام این متغیر را هر چیزی که بگذارید (`code`، `otp`، …) مهم نیست؛ فقط باید در مرحله بعد همان را به سامانه بگویید.
2. از مسیر **تنظیمات › پیامک** در سامانه:
   - **درایور**: IPPanel
   - **کلید دسترسی (API Key)**: از «پنل IPPanel › توسعه‌دهندگان › کلیدهای دسترسی»
   - **شماره فرستنده**: مثلاً `+983000505`
   - **کد الگو (Pattern Code)**: کد الگوی تایید شده
   - **نام متغیر کد در پترن شما**: نام جای‌نگهداری که در متن پترن استفاده کرده‌اید (در مثال بالا: `otp`).
     سامانه مقدار کد تایید را دقیقاً با همین نام به IPPanel می‌فرستد؛ اگر پترن شما `{code}` دارد، پیش‌فرض `code` را نگه دارید.
     بخش «متغیری که سامانه ارسال می‌کند» در همان صفحه، خروجی نهایی را به‌صورت زنده نشان می‌دهد.
3. با دکمه **ارسال تست**، اتصال را بررسی کنید.

### اطلاع‌رسانی‌های خودکار (پترن‌های مجزا)
علاوه بر کد تایید (OTP)، دو پترن دیگر برای اطلاع‌رسانی تعریف کنید:

| پترن | گیرنده | متغیرها |
|------|--------|---------|
| **متقاضی جدید / آماده مصاحبه** | شماره‌های تیم منابع انسانی (قابل تنظیم) | نام متقاضی، موقعیت شغلی، کد پیگیری |
| **تأیید ثبت‌نام** | خود متقاضی | نام متقاضی، کد پیگیری |

برای هر پترن، «نام متغیرها در پترن خود» را در تنظیمات وارد کنید؛ مثلاً اگر پترن شما
`متقاضی جدید: {name} برای {position} با کد {code}` است، نام متغیرها را `name`، `position` و `code` بگذارید.
خروجی دقیق هر پترن در همان صفحه به‌صورت `params = { ... }` نمایش داده می‌شود.

مستندات رسمی: [IPPanel Edge API Docs](https://ippanelcom.github.io/Edge-Document/docs/)

> 💡 در **حالت آزمایشی (Mock)**، کد OTP روی صفحه نمایش داده می‌شود تا بدون پیامک بتوانید همه چیز را تست کنید.

## 🧠 تحلیل شخصیت MBTI

- **۲۸ سوال** در ۴ بُعد (E/I، S/N، T/F، J/P) — دقیقاً مطابق فایل استاندارد شرکت
- تحلیل حرفه‌ای شامل:
  - تیپ ۴ حرفی + عنوان و توصیف کامل فارسی
  - درصد و شدت هر بُعد + تشخیص بُعدهای **مرزی**
  - **تحلیل ترکیبی** بُعدها (ترکیب‌های رفتاری)
  - نقاط قوت/قابل توسعه، سبک کار، نقش تیمی، رهبری، مدیریت استرس، انگیزه‌ها
  - **راهنمای مصاحبه** متناسب با تیپ + نکات هشدار
  - **سازگاری تیپ با موقعیت شغلی** متقاضی
  - **تحلیل پاسخ‌به‌پاسخ** هر سوال و نگاشت آن به بُعد مربوطه
- ⚠️ نتیجه آزمون **فقط برای کارشناسان منابع انسانی و مدیریت** قابل مشاهده است.

## 👤 نقش‌ها و دسترسی‌ها

| نقش | توضیح |
|-----|-------|
| **مدیر کل سامانه** | دسترسی کامل؛ مدیریت کاربران، نقش‌ها، ماژول‌ها و تنظیمات |

## 🛠 اجرای محلی و تست

```bash
npm install          # نصب وابستگی‌ها
npm start            # اجرا روی پورت 3000
npm test             # اجرای ۱۱۵ تست جامع خودکار (E2E)
```

متغیرهای محیطی:

| متغیر | توضیح |
|-------|-------|
| `PORT` | پورت اجرا (پیش‌فرض 3000 — هاست‌ها خودشان تنظیم می‌کنند) |
| `MINIHRM_DATA` | مسیر پوشه داده‌ها (پیش‌فرض `./data`) |
| `MINIHRM_DB_ENGINE` | با مقدار `sqljs` موتور WebAssembly اجباری می‌شود |
| `NODE_ENV` | `production` در هاست |

# 🏢 MiniHRM - سامانه مدیریت منابع انسانی

یک سامانه جامع و مدرن مدیریت منابع انسانی برای شرکت‌ها، ساخته شده با Node.js

## ✨ قابلیت‌ها

### 🔐 مدیریت کاربران و دسترسی‌ها
- **مدیر سیستم (Super Admin)**: دسترسی کامل به تمام بخش‌ها
- **مدیر منابع انسانی**: مدیریت متقاضیان، موقعیت‌ها، فرم‌ساز و گزارشات
- **کارمند منابع انسانی**: مشاهده و بررسی متقاضیان
- **کارمند شرکت**: مشاهده پروفایل شخصی

### 📋 فرآیند استخدام
- تولید **QR Code** اختصاصی برای هر موقعیت شغلی
- احراز هویت متقاضی با **OTP پیامکی** (IPPanel)
- فرم استخدام **چند مرحله‌ای** با قابلیت سفارشی‌سازی
- آزمون شخصیت‌شناسی **MBTI** (۶۰ سؤال استاندارد)
- تحلیل خودکار نتایج MBTI (فقط برای HR و مدیر قابل مشاهده)

### 🏢 مدیریت سازمان
- مدیریت **بخش‌ها و واحدهای سازمانی**
- مدیریت **موقعیت‌های شغلی** با امکان فعال/غیرفعال
- مدیریت **کارمندان**

### 📊 گزارشات و آمار
- داشبورد با آمار لحظه‌ای
- قیف استخدام (QR → فرم → MBTI → تأیید → استخدام)
- توزیع وضعیت متقاضیان
- توزیع انواع شخصیت MBTI
- خروجی CSV از لیست متقاضیان

### ⚙️ سیستم ماژولار
- قابلیت فعال/غیرفعال کردن هر ماژول از بخش تنظیمات
- ماژول‌ها: کاربران، بخش‌ها، موقعیت‌ها، استخدام، فرم‌ساز، MBTI، کارمندان، گزارشات، تنظیمات

### 🎨 رابط کاربری
- طراحی **RTL فارسی** با فونت Vazirmatn
- ریسپانسیو برای موبایل و دسکتاپ
- سایدبار حرفه‌ای با دسترسی سریع
- فرم‌های مرحله‌ای با پیشرفت‌نمای بصری

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js نسخه ۱۶ یا بالاتر

### نصب روی هاست cPanel (بدون SSH)

1. فایل‌ها را آپلود کنید
2. در cPanel بخش **Setup Node.js App** یک اپلیکیشن بسازید
3. `npm install` را اجرا کنید
4. فایل `.env` را از `.env.example` بسازید
5. اپلیکیشن را استارت کنید
6. به آدرس سایت بروید - صفحه نصب نمایش داده می‌شود

### نصب محلی

```bash
git clone <repo-url>
cd minihrm
npm install
cp .env.example .env
# فایل .env را ویرایش کنید
node app.js
```

به `http://localhost:3000` بروید و مراحل نصب را دنبال کنید.

## ⚙️ تنظیمات IPPanel (OTP)

1. در [ippanel.com](https://ippanel.com) ثبت‌نام کنید
2. از بخش Developers → Access Keys، یک کلید API بسازید
3. یک پترن OTP ایجاد کنید با متغیر `code`
4. در بخش تنظیمات سامانه، کلید API و کد پترن را وارد کنید

## 📁 ساختار پروژه

```
minihrm/
├── app.js                    # نقطه ورود اصلی
├── src/
│   ├── database/             # اتصال و ساختار دیتابیس
│   ├── middleware/           # احراز هویت و کنترل دسترسی
│   ├── services/             # سرویس‌های SMS و QR
│   └── modules/              # ماژول‌های اپلیکیشن
├── views/                    # قالب‌های EJS
├── public/                   # فایل‌های استاتیک (CSS, JS)
└── uploads/                  # فایل‌های آپلود شده
```
